# KeyHollow Support

**Public version:** https://www.keyhollow.com/support

KeyHollow V1 is a local-only encrypted photo vault for iPhone. It does not use accounts, KeyHollow cloud storage, Face ID, Touch ID, or the iPhone device passcode as a substitute for a vault passcode.

## Vault access

- Vault passcodes contain 8–20 digits and common predictable patterns are blocked.
- Each passcode opens only its associated vault.
- Passcodes cannot be recovered or reset without opening the vault with its current passcode.
- After repeated incorrect attempts, wait for the displayed cooldown.

## Copy and Move

- **Copy to Vault** keeps the original in Photos.
- **Move to Vault** encrypts and verifies the vault copy before asking iOS to delete the original.
- If deletion is denied or incomplete, KeyHollow treats the import as a copy.
- Do not interrupt an import or remove originals until KeyHollow confirms the result.

## Important data-loss warning

Deleting KeyHollow, erasing or losing the device, deleting a vault, or forgetting its passcode may permanently remove access to locally stored vault contents. KeyHollow does not provide cloud backup or passcode recovery.

## Reporting a problem

Include the KeyHollow version, iOS version, iPhone model, the action you were taking, and any on-screen message. Never send a vault passcode, encryption key, or private photo.

Security reports should include clear reproduction steps and the affected version. Use test media only and never attempt to access another person's device or data.
